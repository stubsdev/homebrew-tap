# Homebrew tap for stubs

    brew install stubsdev/tap/stubs

Installs `stubs`, the command-line tool for the [Stubs](https://stubs.dev) Protobuf registry, from
[stubsdev/cli-releases](https://github.com/stubsdev/cli-releases). The cask in `Casks/` is updated by each release;
don't edit it by hand.
